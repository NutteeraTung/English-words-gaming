# What is this game?
The English word gaming is a multi-player game. That you have to think about the word start with ... and end with ..
## Rules
- First player : Let's guess the words 🧐.. start with n
- Second player : End with e
- And these 2 players have to think about words that start with N and end with e in the 10-secs. Who is answer faster and correct is the winner!!. Then ths next round shuffle the player to pick up the word.
- The answer must be available in the English dictionary.
